# 2、网站主题色与默认模式

建议默认使用**深色主题**。Anime Dice 的视觉卖点是发光骰子、稀有度、Luck、能量特效和动漫角色，深蓝黑背景更能衬托紫色与青色霓虹效果，也更接近玩家对 RNG/抽卡类游戏的直觉。

主色建议：**Galactic Violet**  
辅助高亮：**Electric Cyan**  
奖励/成功状态：**Lucky Green**  
兑换码/稀有物品：**Gold**

```css
/* 导航页主题色 - 亮色主题 */
--nav-theme: 265 82% 54%;        /* galactic violet */
--nav-theme-light: 190 90% 42%;  /* electric cyan */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 268 92% 68%;        /* brighter violet for dark backgrounds */
--nav-theme-light: 190 95% 62%;  /* brighter electric cyan */
```

配套颜色建议：

```css
/* 亮色主题 */
--background: 225 35% 97%;
--foreground: 228 32% 12%;
--card: 0 0% 100%;
--accent: 190 90% 42%;
--success: 148 70% 38%;
--reward: 42 95% 50%;

/* 暗色主题（默认） */
--background: 230 38% 7%;
--foreground: 220 25% 96%;
--card: 229 32% 11%;
--accent: 190 95% 62%;
--success: 148 72% 52%;
```

避免将整站做成高饱和紫色。紫色应主要用于按钮、选中状态与稀有度光效，正文区域保持深蓝黑和高对比白色。

# 3、多语言建议

## 结论：推荐优先级

1. **英语 — Anime Dice**
2. **巴西葡萄牙语 — Dado de Anime**
3. **西班牙语 — Dado de anime**
4. **印度尼西亚语 — Dadu Anime**

不建议首期加入中文；也不建议仅因动漫题材就优先日语，因为 Roblox 攻略与兑换码流量在巴西、拉美和东南亚通常更容易形成规模。

| 优先级 | 语言 | 本地化主题名 | URL 建议 | 选择原因 |
|---:|---|---|---|---|
| 1 | English | Anime Dice | `/en/` | 游戏原始名称、Discord 与代码公告的主要语言，也是全球 SEO 主入口 |
| 2 | Português do Brasil | Dado de Anime | `/pt-br/` | 巴西 Roblox 用户群庞大；[Roblox 官方葡语页面](https://www.roblox.com/pt/games/113290951185459/Anime-Dice)采用该译名 |
| 3 | Español | Dado de anime | `/es/` | 覆盖拉美和西班牙用户；[Roblox 官方西语页面](https://www.roblox.com/es/games/113290951185459/Anime-Dice)采用该译名 |
| 4 | Bahasa Indonesia | Dadu Anime | `/id/` | 印尼 Roblox 与动漫内容受众重合度高；[Roblox 官方印尼语页面](https://www.roblox.com/id/games/113290951185459/Anime-Dice)采用该译名 |

本地化时建议保留以下英文实体，不要直译：

- `Anime Dice`
- `UPDATE7`
- `Lucky Spins`
- `Trait Rerolls`
- `Gems`
- `Tickets`
- 兑换码字符串
- 游戏内角色、骰子、Trait 和 Mutation 的实际显示名称

页面标题可以采用“双名称”结构，例如：

- 葡语：`Dado de Anime Wiki — Códigos de Anime Dice`
- 西语：`Dado de anime Wiki — Códigos de Anime Dice`
- 印尼语：`Dadu Anime Wiki — Kode Anime Dice`

这样既承接本地化搜索词，也不会丢失 `Anime Dice` 的品牌搜索流量。
